# RoughMoor

Manages local file system backups by automating scheduled snapshots and versioning for developers and data analysts.

The key benefits of using RoughMoor include:

- Manages local file system backups
- by automating scheduled snapshots and
- versioning for developers and data

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughMoor.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
